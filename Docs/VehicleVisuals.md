# Car Pawn의 모델 선택과 바퀴 표시

에디터에서 `Car Pawn`을 추가하고 `StaticMeshComponent`의 `StaticMesh`에서 차량을 선택한다.
이 선택은 `AVehiclePawn::SetBody()`를 거쳐 모델과 Box 크기, 카메라 배치에 적용된다.
Lua의 `Car:SetBody("ghini")`처럼 이름으로 바꾸는 경로도 동일하며, 주행 프리셋에 사용하는 `BodyName`은 원본 이름을 유지한다.

Play 시 원본 OBJ의 `o` 경계를 읽어 차체와 네 바퀴를 메모리에서 분리한다.
`armor`, `coupe`, `fenyr`, `ghini`, `italia`, `jeep`, `kamaro`, `lamb`, `mobil`, `police`, `rally`, `van`을 지원한다.
바퀴의 `wheel*` 이름과 엔진 좌표의 중심 위치로 앞뒤/좌우를 구분한다.
각 부분은 자기 중심을 피벗으로 쓰고 원래 위치에 배치하며, 재질과 텍스처는 원본과 공유한다.
같은 차량의 분리 결과는 캐시해서 다른 Car Pawn에서도 재사용한다. 별도의 OBJ 파일은 생성하지 않는다.
네 바퀴 구조가 없는 모델은 원본 메시로 표시한다.

바퀴 회전은 PostPhysics에서 Solver의 실제 속도를 전방에 투영하고 `속도 × 시간 / 월드 반지름`으로 갱신한다.
전진/후진/관성 이동에 맞춰 방향과 속도가 바뀐다. 앞바퀴만 입력에 따라 최대 25도로 꺾이며 지수 보간으로 복귀한다.
바퀴에는 충돌을 추가하지 않으며, 차량의 기존 Box와 Movement/Solver가 물리 계산을 담당한다.

카메라는 선택한 모델의 크기에 따라 차 뒤쪽 위에 배치하고 차량의 +X 전방을 바라본다.
차량 Yaw를 따라가며 수평을 유지하고 기존 부스트 FOV 효과도 사용한다.
OBJ가 .bin 캐시보다 새로 수정되었으면 원본을 다시 읽는다. 좌표계 변경 전 캐시가 차량을 반대로 보이게 하던 문제를 해결한다.

원본 선택은 씬 저장/불러오기와 PIE 복제에 유지된다. 분리한 메시와 표시용 컴포넌트는 일시적인 객체로 취급해 씬/에셋 선택 목록에 저장하지 않는다.

검증: `PhysicsSimulationTests --vehicle-visuals`로 캐시 갱신, 12개 차량 교체, 삼각형 수/배치, 저장/불러오기, 바퀴 회전과 조향, 후방 카메라를 확인한다.
